# Antigravity Implementation Contract

Use Antigravity 3.1 Pro as an implementation worker. The orchestrator approves scope, reviews evidence, and decides whether a milestone is accepted.

Each task must include:

- Phase and milestone name.
- Allowed files or modules.
- Required behavior and public interfaces.
- Required commands to run.
- Required evidence files.
- Explicit non-goals.
- Known failure cases.

Each Antigravity result must report:

- Files changed.
- Commands run.
- Whether commands passed or failed.
- Location of `_evidence/latest/serial.log` when boot testing ran.
- Any skipped checks.
- Remaining risks.

The orchestrator must verify:

- Diff matches the assigned scope.
- Evidence was generated by the current code.
- Serial checkpoints are present.
- Failures are not hidden behind vague summary text.
- Feature work does not bypass unresolved kernel correctness issues.
